# คู่มือผู้ดูแลระบบ

## Dashboard ภาพรวม

เปิดหน้า `/admin` เพื่อดูจำนวนผู้ใช้แยกตามบทบาท จำนวนสัญญา เงินต้นรวม ยอดชำระ ยอดคงค้าง และอัตราดอกเบี้ยเฉลี่ย หน้าเดียวกันมีกราฟสถานะสัญญา กราฟยอดคงค้างรายสัญญา และแนวโน้มการชำระเงินรายเดือน หากไม่มีข้อมูล ระบบจะแสดง empty state แทนกราฟที่ว่าง

## จัดการคำขอกู้

แท็บ **คำขอกู้ที่รอการอนุมัติ** แสดงรายการที่ยังไม่ตัดสินใจ ผู้ดูแลระบบกด **อนุมัติ** เพื่อสร้างสัญญาและตารางผ่อนโดยอัตโนมัติ หรือกรอกเหตุผลแล้วกด **ปฏิเสธ** ระบบตรวจสอบสิทธิ์ฝั่งเซิร์ฟเวอร์ทุกครั้งและส่งการแจ้งเตือนไปยังผู้กู้ตามค่าตั้งค่าของช่องทางนั้น

## ตรวจสอบการชำระเงิน

แท็บ **การชำระเงินที่รอตรวจสอบ** แสดงจำนวนเงิน วิธีชำระ วันที่ และลิงก์สลิป ผู้ดูแลระบบสามารถเปิดหลักฐาน กด **ยืนยัน** หรือกรอกเหตุผลแล้วกด **ปฏิเสธ** หลังดำเนินการ ระบบจะ refresh สถิติและรายการที่รอตรวจสอบ

## จัดการผู้ใช้

แท็บ **จัดการผู้ใช้** แสดงชื่อ อีเมล บทบาท และการเข้าสู่ระบบล่าสุด ผู้ดูแลระบบสามารถเปลี่ยนบทบาทเป็นผู้กู้ ผู้ให้กู้ หรือผู้ดูแลระบบได้ แต่ไม่สามารถลดสิทธิ์ของบัญชีผู้ดูแลระบบที่กำลังใช้งานอยู่ การเปลี่ยนบทบาททำผ่าน protected procedure ที่ตรวจสอบ role ฝั่งเซิร์ฟเวอร์

## การตั้งค่าและความปลอดภัย

ค่าตั้งค่า SMTP และ LINE token ไม่ควรเก็บใน source code ให้ตั้งผ่าน environment variables หรือหน้า Settings ที่จัดเตรียมไว้ การเข้าถึงข้อมูลสัญญา คำขอกู้ และการชำระเงินใช้ protected procedures และตรวจสอบเจ้าของข้อมูลทุกครั้ง ข้อมูลสลิปเก็บใน object storage และฐานข้อมูลเก็บเฉพาะ URL/metadata

## Scheduled payment reminder

ระบบมี endpoint `POST /api/scheduled/payment-reminders` สำหรับ Heartbeat ซึ่งค้นหางวดที่ยังไม่ชำระและครบกำหนดภายใน 3 วัน จากนั้นส่ง in-app, Email และ LINE ตามค่าตั้งค่าของผู้กู้ และใช้ข้อความแจ้งเตือนเพื่อป้องกันการส่งซ้ำ การสร้าง project-level schedule ต้องทำหลัง Deploy production และควรเก็บ `task_uid` ไว้ในค่าคอนฟิกของระบบ

## การ Export CSV

ผู้ดูแลระบบและผู้มีสิทธิ์ตามสัญญาสามารถ Export ตารางผ่อนชำระรายสัญญาได้ โดยกำหนด `startDate` และ `endDate` รูปแบบ `YYYY-MM-DD` ระบบจะตรวจว่า start ไม่หลัง end กรองเฉพาะงวดในช่วงวันที่ และ escape ค่า CSV เพื่อป้องกันข้อมูลเสียรูปแบบเมื่อมีเครื่องหมาย comma, quote หรือขึ้นบรรทัดใหม่


## 8. การ Publish และตั้งค่า Scheduled Heartbeat บน Production

- **การ Publish**: เมื่อระบบสมบูรณ์และผ่านการทดสอบแล้ว ให้คลิกปุ่ม **Publish** ใน Management UI เพื่อเผยแพร่เว็บแอปพลิเคชันไปยังโดเมนส่วนตัว (เช่น `loanapp-juxypduw.manus.space`)
- **การตั้งค่า Heartbeat Schedule**: หลังจาก Publish แล้ว ให้ตั้งค่าระบบ Cron / Heartbeat ของโฮสติ้งให้เรียกใช้งาน `POST /api/scheduled/payment-reminders` ทุกวัน (ระบบจะตรวจสอบงวดที่ครบกำหนดในอีก 3 วันข้างหน้า พร้อมส่งการแจ้งเตือนตามช่องทางที่ผู้ใช้เปิดไว้และป้องกันการส่งซ้ำ)
