# คู่มือผู้ใช้ระบบจัดการเงินกู้

## การเข้าสู่ระบบ

ระบบใช้ Manus OAuth สำหรับการสมัครสมาชิกและเข้าสู่ระบบ ผู้ใช้ไม่ต้องสร้างหรือเก็บรหัสผ่านไว้ในระบบโดยตรง หลังเข้าสู่ระบบ ระบบจะนำทางไปยัง Dashboard ตามบทบาทที่ได้รับ ได้แก่ ผู้กู้ ผู้ให้กู้ หรือผู้ดูแลระบบ

## การสร้างคำขอกู้

ผู้กู้เลือกเมนู **สร้างคำขอกู้** ระบุจำนวนเงิน ระยะเวลาผ่อน ประเภทดอกเบี้ย อัตราดอกเบี้ยต่อปี และรูปแบบค่างวด จากนั้นตรวจสอบยอดชำระรวมและค่างวดที่ระบบคำนวณให้ก่อนส่งคำขอ คำขอที่ส่งแล้วจะมีสถานะรอการอนุมัติ

## การดูสัญญาและตารางผ่อน

เมื่อคำขอได้รับอนุมัติ ระบบจะสร้างสัญญาและตารางผ่อนชำระ ผู้กู้สามารถเปิดรายละเอียดสัญญา ดูยอดคงค้าง กราฟการลดหนี้ และดาวน์โหลดตารางผ่อนเป็น CSV ได้ หากต้องการดาวน์โหลดเฉพาะบางช่วง ให้กำหนดวันเริ่มต้นและวันสิ้นสุดก่อนกด **Export CSV**

## การชำระเงิน

จากหน้ารายละเอียดสัญญาให้เลือก **ชำระเงิน** ระบุจำนวนเงินและวิธีชำระ ระบบรองรับ PromptPay QR และการอัปโหลดสลิป JPEG, PNG หรือ PDF ขนาดไม่เกิน 5 MB หลังส่งสลิป สถานะจะเป็นรอตรวจสอบจนกว่าผู้ให้กู้หรือผู้ดูแลระบบจะยืนยัน

## การตั้งค่าการแจ้งเตือน

หน้า **ตั้งค่าการแจ้งเตือน** ให้ผู้ใช้เปิดหรือปิดการแจ้งเตือนอีเมลและ LINE แยกตามเหตุการณ์ เช่น คำขอกู้ใหม่ การอนุมัติ การปฏิเสธ และการเตือนกำหนดชำระ การเชื่อมต่อ LINE ต้องใช้ access token ของผู้ใช้เองและสามารถส่งข้อความทดสอบหรือยกเลิกการเชื่อมต่อได้

> ข้อควรทราบ: การส่งอีเมลจริงต้องตั้งค่า SMTP ฝั่งเซิร์ฟเวอร์ และการส่ง LINE ต้องมี token ที่ยังใช้งานได้ ระบบจะบันทึกการแจ้งเตือนในระบบแม้ช่องทางภายนอกถูกปิด
