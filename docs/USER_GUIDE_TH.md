# คู่มือการใช้งานระบบจัดการเงินกู้

คู่มือนี้อธิบายการใช้งานฟังก์ชันที่มีอยู่ในระบบสำหรับผู้กู้ ผู้ให้กู้ และผู้ดูแลระบบ ระบบจะแสดงเมนูและข้อมูลตามสิทธิ์ของบัญชีที่เข้าสู่ระบบ หากพบข้อความว่าไม่มีสิทธิ์เข้าถึง ให้ตรวจสอบบทบาทผู้ใช้กับผู้ดูแลระบบก่อนดำเนินการต่อ

> **ข้อควรระวัง:** ใช้ข้อมูลและเอกสารการเงินจริงที่ผ่านการอนุมัติขององค์กรเท่านั้น หลีกเลี่ยงการใส่รหัสผ่าน token หรือข้อมูลบัญชีธนาคารลงในชื่อ Preset, หมายเหตุ หรือช่องค้นหา

## 1. เริ่มต้นใช้งาน

เข้าสู่ระบบผ่านหน้าแรกของระบบ เมื่อสำเร็จให้ตรวจสอบชื่อบัญชีและเมนูโปรไฟล์บริเวณแถบด้านข้างหรือส่วนหัว ใช้ปุ่มสลับธีมเพื่อเลือกระหว่างโหมดสว่างและมืด และใช้เมนูโปรไฟล์เพื่อเข้าสู่หน้า **โปรไฟล์** หรือ **ตั้งค่าการแจ้งเตือน**

| เมนู | วัตถุประสงค์ | ผู้ใช้ที่เกี่ยวข้อง |
|---|---|---|
| Dashboard | ดูสถานะเงินกู้ ยอดคงค้าง และรายการที่ต้องดำเนินการ | ทุกบทบาทตามสิทธิ์ |
| สร้างคำขอกู้ | ยื่นคำขอกู้และกำหนดเงื่อนไข | ผู้กู้ |
| รายละเอียดสัญญา | ดูตารางผ่อน ประวัติ และชำระเงิน | ผู้มีสิทธิ์ในสัญญา |
| ศูนย์ควบคุม Admin | ดูภาพรวมและจัดการ Preset | ผู้ดูแลระบบ |
| Activity History / Audit Logs / การกำกับรายงาน | ตรวจสอบเหตุการณ์และการนำข้อมูลออก | ผู้ดูแลระบบที่ได้รับสิทธิ์ |

## 2. สำหรับผู้กู้: สร้างและติดตามคำขอกู้

เลือก **สร้างคำขอกู้** จากเมนู Dashboard กรอกจำนวนเงิน ระยะเวลาผ่อน ประเภทดอกเบี้ย อัตราดอกเบี้ยต่อปี และข้อมูลประกอบที่ระบบกำหนด ตรวจสอบยอดรวม ค่างวด และตารางผ่อนที่ระบบคำนวณก่อนกดส่งคำขอ ระบบจะแจ้ง validation หากกรอกข้อมูลไม่ครบหรือค่าอยู่นอกเกณฑ์

หลังผู้ให้กู้หรือผู้ดูแลระบบพิจารณาแล้ว ให้เปิด **รายละเอียดสัญญา** เพื่อตรวจสถานะ ยอดคงเหลือ ตารางชำระ และประวัติการจ่าย ใช้ปุ่มส่งออก CSV ในส่วนตารางผ่อนเมื่อจำเป็นต้องนำข้อมูลไปตรวจสอบในโปรแกรมสเปรดชีต

## 3. การชำระเงินและสลิป

จากรายละเอียดสัญญา เลือกรายการงวดที่ต้องการชำระและเข้าสู่หน้า **ชำระเงิน** อัปโหลดหลักฐานตามชนิดและขนาดไฟล์ที่หน้าเว็บกำหนด จากนั้นตรวจจำนวนเงิน วันที่ และรายละเอียดก่อนส่ง ระบบจะบันทึกรายการเป็นสถานะรอตรวจสอบจนกว่าผู้มีสิทธิ์จะยืนยันหรือปฏิเสธ

หากถูกปฏิเสธ ให้เปิดรายละเอียดรายการเพื่ออ่านเหตุผลที่ได้รับ และส่งหลักฐานฉบับแก้ไขตามกระบวนการองค์กร ไม่ควรส่งหลักฐานซ้ำโดยไม่ตรวจสถานะเดิมก่อน

## 4. สำหรับผู้ให้กู้: พิจารณาคำขอและตรวจการชำระ

เปิด Dashboard เพื่อดูรายการคำขอหรือการชำระที่รอดำเนินการ เลือกรายการเพื่ออ่านรายละเอียด เงื่อนไขดอกเบี้ย และตารางผ่อนก่อนเลือก **อนุมัติ**, **ปฏิเสธ** หรือ **ยืนยันการชำระ** ระบบจะแสดงหน้าต่างยืนยันก่อนการกระทำสำคัญ เพื่อลดความเสี่ยงจากการกดโดยไม่ตั้งใจ

ก่อนยืนยันการชำระ ให้ตรวจว่าเลขสัญญา จำนวนเงิน งวด และหลักฐานตรงกัน หากข้อมูลไม่เพียงพอให้ปฏิเสธพร้อมเหตุผลตามนโยบาย ไม่ควรยืนยันรายการนอกสัญญาหรือเกินสิทธิ์ของบัญชี

## 5. การตั้งค่าโปรไฟล์และการแจ้งเตือน

เลือก **โปรไฟล์** เพื่อจัดการรูปภาพและรูปแบบการแสดงผลส่วนบุคคล สามารถลบรูปภาพเพื่อกลับไปใช้ค่าเริ่มต้นได้ เลือก **ตั้งค่าการแจ้งเตือน** เพื่อเปิดหรือปิดช่องทางที่ระบบรองรับตามสิทธิ์ของคุณ การเปลี่ยนแปลงการตั้งค่าจะถูกบันทึกเป็น audit event เพื่อการตรวจสอบ

การเปิดสวิตช์ไม่ได้แทนที่การตั้งค่าผู้ให้บริการภายนอก ผู้ดูแลระบบต้องกำหนด SMTP/ช่องทาง LINE ที่องค์กรอนุมัติให้เรียบร้อยก่อนการแจ้งเตือนภายนอกจะส่งได้จริง

## 6. สำหรับผู้ดูแลระบบ: Dashboard และการวิเคราะห์

เปิด **ศูนย์ควบคุม Admin** เพื่อดู KPI, แนวโน้มการชำระเงิน, สัดส่วนสถานะ และรายการกิจกรรม ใช้ตัวเลือก 7/30/90 วันหรือกำหนดช่วงวันที่เองเพื่อปรับข้อมูลบนหน้าจอ การคลิก KPI หรือส่วนของกราฟที่รองรับจะเปิดรายละเอียดเชิงลึกตามข้อมูลที่บัญชีมีสิทธิ์ดู

ใช้ปุ่มส่งออกภาพหรือ PDF ของกราฟเฉพาะเมื่อมีข้อมูลแสดงอยู่ หากไม่มีข้อมูล ระบบจะแสดง empty state แทนการสร้างตัวเลขขึ้นมาเอง เพื่อป้องกันการตีความผิด

## 7. Dashboard Presets และโฟลเดอร์

Preset ใช้เก็บช่วงวันที่ที่ใช้บ่อย ผู้ดูแลระบบสามารถบันทึก Preset ส่วนตัว แชร์ Preset ที่ตนเป็นเจ้าของ คัดลอก Preset ของทีมเป็นสำเนาส่วนตัว และปักหมุดรายการที่ใช้บ่อยได้ รายการของทีมที่ไม่ได้เป็นเจ้าของจะเป็นแบบอ่านอย่างเดียวจนกว่าจะคัดลอก

### 7.1 จัดโฟลเดอร์และเลือกหลาย Preset

ในส่วน **โฟลเดอร์และตัวกรอง Preset หมุด** ให้สร้างโฟลเดอร์ ตั้งชื่อ เลือกสีและไอคอน จากนั้นเลือก Preset ด้วย checkbox แล้วเลือกโฟลเดอร์ปลายทางหรือใช้ drag handle เพื่อลากรายการที่เลือกไปยังโฟลเดอร์เป้าหมาย ระบบจะขอให้ยืนยันเมื่อย้ายหลายรายการข้ามโฟลเดอร์

| งาน | วิธีใช้งาน |
|---|---|
| ค้นหาโฟลเดอร์ | ใช้ช่อง **ค้นหาโฟลเดอร์** และตัวกรองว่าง/มี Preset |
| แยกตามลักษณะ | ใช้ **กรองสี** และ **กรองไอคอน** |
| เรียงโฟลเดอร์ | เลือกเรียงตามชื่อ, จำนวน Preset มากไปน้อย หรือ น้อยไปมาก |
| เปลี่ยนชื่อ/ลบ | ใช้ปุ่มใน chip ของโฟลเดอร์; การลบจะล้างเฉพาะ mapping ของบัญชีคุณ |
| เคลียร์การเลือก | กด **ยกเลิกการเลือก** โดยไม่กระทบการจัดกลุ่มเดิม |

การลากเพื่อจัดลำดับ Preset ที่ปักหมุดจะถูกปิดเมื่อมีตัวกรองที่ซ่อนรายการบางส่วน เพราะระบบต้องเห็นชุดหมุดครบทั้งหมดก่อนบันทึกลำดับ ให้ล้างตัวกรองก่อนใช้การจัดลำดับ แต่การย้ายเข้าโฟลเดอร์ยังใช้ชุดรายการที่เลือกและผ่านการตรวจสิทธิ์บนเซิร์ฟเวอร์ทุกครั้ง

### 7.2 ประวัติการย้าย, Undo/Redo และ CSV

ส่วน **ประวัติการย้าย Preset** แสดง metadata ล่าสุดของบัญชีคุณ ได้แก่ เวลา จำนวนรายการ โฟลเดอร์ปลายทาง และสถานะ ใช้ **Undo** เพื่อย้อนกลับการย้ายล่าสุด หรือ **Redo** เพื่อทำซ้ำการย้ายที่เพิ่ง Undo ไป ระบบจะตรวจว่า Preset และโฟลเดอร์ยังอยู่ในสิทธิ์ก่อนเปลี่ยนข้อมูล

กด **CSV** เพื่อดาวน์โหลดประวัติที่แสดงในรูปแบบตาราง ไฟล์ประกอบด้วยเวลา จำนวน Preset โฟลเดอร์ปลายทาง และสถานะเท่านั้น จึงไม่รวมรหัส Preset หรือ snapshot ภายใน

## 8. Activity History, Audit Logs และ Governance

หน้า **Activity History** ช่วยค้นหาเหตุการณ์อนุมัติและตรวจการชำระตามช่วงวัน ประเภท ผู้ดำเนินการ บทบาท และผู้ให้กู้ สามารถบันทึกชุดตัวกรองและส่งออกผลที่กรองแล้วเป็น CSV/PDF ได้

หน้า **Audit Logs** ใช้ตรวจการอ่านหรือแก้ไขการตั้งค่าที่มีการบันทึกไว้ เลือกช่วงวันที่ ค้นหาตามชื่อหรืออีเมล และเปิดรายละเอียดรายการได้ การเข้าถึงและการส่งออกถูกจำกัดตามสิทธิ์ที่ระบบกำหนด

หน้า **การกำกับรายงาน** ใช้ติดตามการส่งออก กำหนดนโยบาย และจัดการคำขอที่ต้องใช้ dual-control ก่อนส่งออกข้อมูลละเอียด ผู้ขอไม่สามารถอนุมัติคำขอของตนเองได้

## 9. แนวทางแก้ปัญหาเบื้องต้น

| อาการ | แนวทางดำเนินการ |
|---|---|
| เห็นข้อความไม่มีสิทธิ์ | ออกจากระบบ/เข้าสู่ระบบใหม่ แล้วให้ Admin ตรวจบทบาทของบัญชี |
| หน้าแสดงกำลังโหลดนาน | ตรวจการเชื่อมต่อและลองรีเฟรชหนึ่งครั้ง; หากยังเกิดให้บันทึกเวลาและหน้าจอแจ้งผู้ดูแล |
| Export ไม่ทำงาน | ตรวจว่ามีผลลัพธ์ในหน้าจอและสิทธิ์ export เพียงพอ; อย่าปิดหน้าต่างระหว่างสร้างไฟล์ |
| ไม่พบ Preset/โฟลเดอร์ | ตรวจ scope/filter สี/ไอคอน/โฟลเดอร์ว่าง และยืนยันว่ากำลังใช้บัญชีเดิม |
| Undo/Redo ใช้ไม่ได้ | ทำได้เฉพาะการย้ายล่าสุดของบัญชี และจะใช้ไม่ได้หากข้อมูลหรือโฟลเดอร์ที่เกี่ยวข้องไม่อยู่ในสิทธิ์แล้ว |

## 10. ข้อมูลที่ควรแจ้งเมื่อขอความช่วยเหลือ

โปรดแจ้งบทบาทผู้ใช้ หน้าจอที่ใช้งาน ขั้นตอนที่ทำให้เกิดปัญหา วันและเวลา ข้อความ error และเลขอ้างอิงที่ปกปิดข้อมูลส่วนบุคคลแล้ว ห้ามส่งรหัสผ่าน token ข้อมูลบัญชีธนาคาร หรือไฟล์สลิปผ่านช่องทางที่ไม่ผ่านการอนุมัติขององค์กร
