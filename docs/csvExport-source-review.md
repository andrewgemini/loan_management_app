# CSV Export Source Review

เอกสารนี้จัดทำเพื่ออธิบายและอ้างอิงซอร์สโค้ดที่ใช้สร้างไฟล์ CSV ตารางผ่อนชำระของแต่ละสัญญาเงินกู้

## ไฟล์ต้นฉบับ

ซอร์สโค้ดฉบับเต็มอยู่ที่ `server/csvExport.ts` และถูกส่งมอบเป็นไฟล์แนบพร้อมรายงานนี้ เพื่อให้ตรวจสอบได้ตรงกับโค้ดที่ใช้งานจริง

## รูปแบบข้อมูลหลัก

| อินเทอร์เฟซ | ข้อมูลสำคัญ |
|---|---|
| `AmortizationRow` | เลขงวด วันครบกำหนด ยอดต้นงวด เงินต้น ดอกเบี้ย ยอดชำระ และยอดปลายงวด |
| `LoanInfo` | เลขสัญญา ผู้กู้ เงินต้น อัตราดอกเบี้ย ระยะเวลา วันเริ่มต้น วันสิ้นสุด และประเภทการคำนวณ |
| `ExportDateRange` | `startDate` และ `endDate` ในรูปแบบ `YYYY-MM-DD` โดยทั้งสองค่าเป็น optional |

## ฟังก์ชันที่ใช้งาน

`filterAmortizationScheduleByDateRange()` กรองงวดแบบรวมวันเริ่มต้นและวันสิ้นสุด และรองรับช่วงแบบเปิดด้านใดด้านหนึ่ง

`generateAmortizationCSV()` สร้าง CSV ที่มีส่วนข้อมูลสัญญา ส่วนช่วงวันที่ที่เลือก และหัวตาราง/แถวตารางผ่อนชำระ โดย escape comma, quote และ newline ให้ถูกต้อง

`generateCSVFilename()` สร้างชื่อไฟล์พร้อมเลขสัญญา ช่วงวันที่ และ timestamp ส่วน `createCSVBlob()` เพิ่ม UTF-8 BOM เพื่อให้โปรแกรม spreadsheet อ่านภาษาไทยได้ถูกต้อง

## การเชื่อมต่อกับ API

`server/routers/exportRouter.ts` รับ `loanId`, `startDate` และ `endDate` ตรวจสอบรูปแบบวันที่และไม่อนุญาตให้วันสิ้นสุดก่อนวันเริ่มต้น จากนั้นตอบกลับ `csvContent`, `filename`, `contentType`, `rowCount` และ `dateRange`

หากช่วงวันที่ไม่มีงวด ระบบยังสร้างไฟล์ CSV ที่มีข้อมูลสัญญาและหัวตาราง พร้อมแจ้งจำนวนรายการเป็นศูนย์ แทนการทำให้การดาวน์โหลดล้มเหลว
